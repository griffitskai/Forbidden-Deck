# Roadmap

## Milestone 1 — Combat Polish
- animacje zagrywania kart,
- feedback trafień / bloku / leczenia,
- krótkie efekty combo,
- lepsze rozróżnienie przeciwników wizualnie.

## Milestone 2 — Deck Control
- ulepszanie kart przy ognisku,
- usuwanie kart,
- podgląd talii / discard / draw pile,
- rarity jako informacja, nie grind dla grindu.

## Milestone 3 — Status Effects
- krwawienie,
- trucizna,
- podpalenie,
- osłabienie / podatność,
- karty i wrogowie zbudowani wokół statusów.

## Milestone 4 — Act III
- nowy biom,
- nowe archetypy wrogów,
- nowe elity,
- boss wykorzystujący mechaniki statusów i ekwipunku.

## Milestone 5 — Persistence
- zapis ustawień i progresji,
- kolekcja odkrytych kart,
- historia runów,
- przygotowanie do wersji desktop/Steam.
